Lesson 13 · Conditionals

What you will learn

Conditional sentences contain an if-clause (the condition) and a main clause (the result). This lesson covers Type 0, 1, 2 and 3, mixed conditionals, unless, provided that / as long as / suppose, special uses of will / would / should in the if-clause, and formal inversion (Should…, Were…, Had…).

TypeIf-clauseMain clauseMeaning
0present simplepresent simplealways true
1present simplewill + infinitivereal / likely future
2past simplewould + infinitiveimaginary present or future
3past perfectwould have + ppimaginary past
🔁
In plain wordsThe further back the verb in the if-clause (present → past → past perfect), the less real the situation.
IELTS tipIn Speaking Part 3 use Type 2: If governments invested more in education, young people would have better opportunities. In Writing Task 2 use Type 1 for results and Type 2 for hypothetical solutions.

Part 1

The four types

Real and imaginary situations.

Type 0 and Type 1: real

core learn these first · less common learn these second

a

Type 0 — always true: if / when + present simple, present simplecore

Is it a fact or a rule?
  • If the temperature falls below 0 °C, water turns into ice.
  • When the sun shines, snow melts.
b

Type 1 — real / likely future: if + present, will / can / may + infinitivecore

Is it likely?
  • If he doesn't pay the fine, he will go to prison.
  • If you have finished your work, we can have a break. (present perfect in the if-clause)
  • If you need help, come and see me. (imperative)

Type 2 and Type 3: imaginary

c

Type 2 — imaginary present: if + past simple, would + infinitivecore

Is it unreal or unlikely now?
  • If I had time, I would take up a sport. (I don't have time)
  • If I were you, I would talk to my parents. (advice)
d

Type 3 — imaginary past: if + past perfect, would have + ppcore

Is it past and can't be changed?
  • If she had studied harder, she would have passed. (regret or criticism)
  • If he hadn't been acting so foolishly, he wouldn't have been punished.

Same verb, two ideas:

If I have time, I'll help you.real: it is possible
If I had time, I'd help you.imaginary: I haven't got time
🧭
Ask yourself“Is it true or likely (Type 0 / 1)? Is it imaginary now (Type 2)? Is it imaginary and in the past (Type 3)?”

Typical mistakes

If it will rain, we stay home.
If it rains, we will stay home.
If I would have time, I would help.
If I had time, I would help.
If I had known, I would told you.
If I had known, I would have told you.
If I was you…
If I were you… (formal, advice)
Part 2

Mixed conditionals and special uses

Time mix, will / would, should.

Mixed conditionals

We mix types when the time of the condition is different from the time of the result.

PatternExampleMeaning
if + past perfect, would + infinitiveIf I had studied medicine, I would be a doctor now.past cause → present result
if + past simple, would have + ppIf I were taller, I would have joined the team.permanent state → past result

will, would and should in the if-clause

  • Normally no will / would after if: If the weather is fine, we will go camping.
  • will in the if-clause = polite request: If you will fill in this form, I'll process it.
  • will not = insistence: If you will not stop shouting, you'll have to leave.
  • if … will after uncertainty: I don't know if he will pass. (= whether)
  • should = possible but not very likely: If Tom should call, tell him I'll be late.

Typical mistakes

If he would have known, he would have called.
If he had known, he would have called.
Part 3

unless, other words and inversion

More ways to say if.

Words instead of if

WordMeaningExample
unlessif … not (verb is affirmative)Unless you leave now, you'll miss the bus.
provided / providing that · as long asonly ifYou can see Mr Carter provided you have an appointment.
suppose / supposingwhat ifSuppose the boss came now, what would you say?
in caseto be preparedTake an umbrella in case it rains.

Inversion (formal): omit if

TypeWith ifInverted
1If Peter should come…Should Peter come, tell him to wait.
2If I were you…Were I you, I wouldn't trust him.
3If he had known…Had he known, he would have called.
IELTS tipInversion with Had / Were / Should is a signal of band 8+ grammar in Writing Task 2: Were governments to invest more in public transport, congestion would fall.

Typical mistakes

Unless you don't hurry…
Unless you hurry…
Had he knew…
Had he known…

Part 5

Speaking: real and imaginary

Work in pairs. First speak, then (if you like) write.

Task 1 · What if…? Type 2

Ask each other: What would you do if…? Make the questions silly and creative.

Task 2 · If only I had… Type 3

Tell your partner about two decisions you regret: If I had…, I would have…

Task 3 · Chain game Type 1

Chain: If I get up late, I'll miss the bus. If I miss the bus, I'll be late for work… Continue for as long as you can.
